### Port-Forwarding and Tunneling Tools

**Description:**
  These are collection of tools which can be used in port forwarding and pivoting to internal networks


The included tools are:
  - **Chisel v1.10.1**
  - **Ligolo-ng v0.7.2**
  - **Plink.exe**


Official repositories to download these tools:
  - [chisel](https://github.com/jpillora/chisel/releases)
  - [ligolo-ng](https://github.com/nicocha30/ligolo-ng/releases)
